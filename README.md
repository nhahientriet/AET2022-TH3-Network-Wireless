AET2022 - TH3 Network Wireless

Họ tên: Phan Công Tuấn Anh

Nội dung thực hiện

Bài 1 - WiFi AP/STA

Thiết lập ESP32 hoạt động ở chế độ AP và STA.
Kết nối WiFi thành công và tạo Access Point.

Bài 2 - BLE Server

Tạo BLE Server trên ESP32.
Thiết bị BLE được phát hiện từ điện thoại.

Bài 3 - ESP-NOW

Truyền dữ liệu giữa hai ESP32 bằng ESP-NOW.
Gửi và nhận dữ liệu thành công.

Bài 4 - HTTP LED Control

Xây dựng Web Server trên ESP32.
Điều khiển LED qua trình duyệt web.

Bài 5 - MQTT Publish/Subscribe

Gửi dữ liệu bằng Publisher.
Nhận dữ liệu bằng Subscriber thông qua MQTT Broker.
Kết luận

Đã thực hiện các bài thực hành về kết nối không dây trên ESP32 gồm WiFi, BLE, ESP-NOW, HTTP Server và MQTT.
